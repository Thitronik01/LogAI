# LogAI

Open-source command-line tool that analyses existing DNS, proxy and firewall log exports locally and shows which AI services were reached from a network. Fully offline, evidence-based, no personal profiles.

**Status:** pre-alpha. There is nothing to run yet.

- Project layout and responsibilities: [docs/REPO_STRUCTURE.md](docs/REPO_STRUCTURE.md)
- Instructions for coding agents: [CLAUDE.md](CLAUDE.md) and [AGENTS.md](AGENTS.md)

The name is provisional; see the open decisions in the repo structure document.
