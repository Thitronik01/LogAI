# Use of the LogAI name and logo

The project uses **LogAI** as its provisional name and **Randbeleg** as its visual identity. The name, wordmark, symbol and combined logo have separate usage terms from the Apache-2.0 code. Section 6 of the code licence covers customary identification of the work’s origin and reproduction of notices. [Repository licence](../LICENSE)

## Uses the project welcomes

- Name LogAI accurately in documentation, reviews, research, compatibility statements and attribution.
- Show the supplied logo when linking to or discussing the upstream project. Keep the artwork intact, follow the [brand guide](README.md) and make the relationship clear.
- Describe a fork as “based on LogAI” and identify the fork’s own name and maintainer. Preserve required attribution and licence notices.

## Uses that need separate permission

Ask the project maintainer before using the name or logo as the identity of a different product, hosted service, organisation or merchandise, or as a badge of approval. Obtain express permission before presenting an association as official. Describe independent integrations and forks accurately. Altered artwork requires permission for use as an official project mark.

These project guidelines preserve uses permitted by applicable law. Font redistribution follows the SIL Open Font License supplied with each font.
